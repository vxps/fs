# FitSpot MVP v2.1 — локальная версия и деплой

**Публикация:** см. [DEPLOY.md](DEPLOY.md) — GitHub + Netlify + Render + Neon.

**Стек:** React 19 + TypeScript + Vite 6; FastAPI + SQLAlchemy + SQLite для быстрого локального запуска. PostgreSQL можно подключить через `DATABASE_URL` (схема БД написана на SQLAlchemy). Docker, оплата, CRM клубов и Telegram-бот не требуются.

## Что реализовано

- Светлый адаптивный дизайн FitSpot без стоковых и ИИ-фотографий: тренеры представлены эмодзи, на главной вместо фотографии — CSS-иллюстрация теннисных ракеток.
- Вход и регистрация с выбором роли **игрок / тренер**; JWT и безопасное хеширование паролей.
- Игрок **обязательно** заполняет анкету после регистрации (спорт, опыт, уровень, район, удобное время, главный приоритет, цель), иначе продолжить нельзя. Данные сохраняются на сервере.
- Каталог **100 условных кортов**: 10 вымышленных клубов по 10 кортов, 60 теннисных и 40 падел-кортов. Статические расписания на 14 дней; при создании новых окон тренером создаются соответствующие демонстрационные окна корта.
- Лента предложений **тренер + корт + свободный слот**, фильтры по спорту, району, дате и времени суток, сортировка по общей стоимости, рейтингу, времени или цене корта. Показываются стоимость тренера, корта и итог.
- Просмотр тренера, выбор доступного слота и корта, анкета заявки и создание предварительной записи в базе.
- Подтверждение условной брони корта **по произвольному непустому номеру**: игрок, если корт бронирует игрок; тренер — если корт бронирует тренер. Зафиксированы разные полномочия пользователей.
- Статусы: `awaiting_court → confirmed → completed` или `no_show`; возможно `cancelled`. Отмена освобождает и слот тренера, и окно корта. Тренер отмечает проведённую тренировку или неявку.
- Тренер заполняет обязательную анкету: фото для проверки, Telegram, описание, стаж, уровни, виды спорта, формат/цены тренировок, клубы, кто бронирует корт, условия отмены. После проверки администратором профиль появляется в поиске. В кабинете можно открыть окно и повторить по неделям, посмотреть/отменить окно и заявки.
- Администратор просматривает анкету нового тренера и может её одобрить.

## Что пока не реализовано

Реальная оплата, холд/возвраты/комиссии, выплаты, SMS и Telegram-бот, CRM клубов, подтверждение фактической брони на стороне клуба, тренерские сплиты и группы как отдельные типы заявок, календарное расписание реальных клубов, A/B-эксперименты H1–H3. Ранжирование сейчас детерминированное **демонстрационное**, это не экспериментальный алгоритм магистерской ВКР.

**Важно:** сервис не бронирует корт в реальном клубе. Номер подтверждения принимается как демонстрационный ввод, без внешней проверки. Отметку `Проведена` тренер может поставить и до фактического начала занятия для демонстрации сценария — в настоящем пилоте необходимо добавить ограничение по времени и правила расчётов.

## Первый запуск на Windows (PowerShell)

Для избежания конфликта **остановите оба сервера предыдущей версии** (`Ctrl+C` в терминалах с Vite и Uvicorn). Распакуйте новый архив **в отдельную папку**, не поверх старого MVP, и откройте папку `fitspot-mvp-v2` в VS Code. Нужны Python 3.11+ и Node.js 22/24.

**Упрощённый способ:** запустите в корне папки `start-backend.cmd` и `start-frontend.cmd` (двумя отдельными окнами). Скрипты сами установят отсутствующие зависимости и запустят серверы. Если хотите контролировать всё вручную, используйте команды ниже.

**Терминал №1 — backend** (от корня папки `fitspot-mvp-v2`):

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

FastAPI: http://127.0.0.1:8000/docs

**Терминал №2 — frontend** (от корня папки `fitspot-mvp-v2`):

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

FitSpot: http://127.0.0.1:5173/

Если вы запускаете второй терминал из папки `backend`, сначала перейдите в соседнюю папку через `cd ..\frontend`. `npm.cmd` обходит блокировку скрипта `npm.ps1` политикой PowerShell. В обоих терминалах должны оставаться запущенные серверы.

### macOS / Linux

```bash
cd backend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Отдельный терминал:

```bash
cd frontend
npm install
npm run dev
```

## Как показать сквозной сценарий

1. Зарегистрируйтесь **игроком** с новым email, заполните обязательную анкету.
2. На вкладке **«Найти тренировку»** посмотрите сочетания тренеров и кортов, поменяйте сортировку и фильтры.
3. Откройте карточку тренера, выберите дату, время, корт и создайте предварительную запись.
4. В **«Моих записях»** посмотрите статус. Если корт бронирует игрок, нажмите «Подтвердить корт» и введите любой номер, например `FS-101`.
5. Если корт бронирует тренер, выйдите и войдите под его демонстрационным аккаунтом. В **«Заявках учеников»** подтвердите корт.
6. Тренер может отметить «Проведена» или «Неявка». Любая запись видна обеим сторонам.
7. Для проверки регистрации тренера создайте **новый** аккаунт тренера, заполните анкету с фото и выберите корты. Он будет со статусом «На проверке». Зайдите в админ-профиль и одобрите — новый тренер появится в поиске (после открытия слотов).

## База данных

SQLite создаётся автоматически по пути `backend/fitspot.db`. В новой поставке **нет** файла базы — он появится при первом старте FastAPI. Данные между перезапусками сохраняются.

Чтобы начать демонстрацию заново, остановите backend, удалите `backend/fitspot.db` (если ваши собственные аккаунты больше не нужны) и перезапустите FastAPI. Seed снова создаст 100 кортов, окна и демо-тренеров.

Для PostgreSQL используйте `DATABASE_URL=postgresql+psycopg://user:password@localhost:5432/fitspot` в `backend/.env` (образец `backend/.env.example`). Для будущего боевого запуска необходимы миграции БД, HTTPS, ограничения запросов, управление сессиями, проверка загружаемых файлов и настройка хранения фото в объектном хранилище.

## Проверки разработчика

Из папки `backend`:

```powershell
python -m pytest -q
```

Четыре интеграционных теста покрывают 100 кортов, фильтрацию и ранжирование, регистрацию/анкеты, обе ветки бронирования, проверку доступа, отмену и регистрацию/модерацию тренера.

Из папки `frontend` после `npm.cmd install`:

```powershell
npm.cmd run build
```
